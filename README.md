# Social Media Backend API

This is a simple backend for a social media application built with **Node.js**, **Express**, and **MongoDB**.  
It handles user authentication, posts, comments, stories, messaging, and more.

---

## Features

- User registration, login, logout
- JWT-based authentication
- Create, read, update, delete posts
- Comment on posts
- Stories feature
- Real-time messaging between users
- Protected routes for authenticated users

---

## Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- Bcrypt for password hashing
- Cookie Parser for sessions
